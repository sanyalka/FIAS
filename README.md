
# Модуль проверки адресов РФ

Пакет для бесплатного локального обучения модуля проверки адресов Российской Федерации на основе официальных данных **ФИАС (Федеральная информационная адресная система)**.

**Компактный размер обученного модуля — около 2 ГБ вместо 400 ГБ исходных XML-данных.**

Вы можете самостоятельно обучить модуль совершенно бесплатно или получить уже готовую обученную версию на Boosty.

## Возможности

- Проверка корректности адресов Российской Федерации.
- Распознавание структуры адреса: регион, район, город, населённый пункт, улица, дом.
- Использование официальной адресной базы ФИАС.
- Локальная работа без обращения к сторонним API.
- Компактное хранение адресных данных.
- Бесплатное самостоятельное обучение.

## Самостоятельное обучение

Для обучения потребуется **Python**, библиотека **NumPy** и официальная XML-выгрузка ФИАС.

### Шаг 1. Скачать базу ФИАС

1. Перейдите на [официальный сайт ФИАС](https://fias.nalog.ru/FiasInfo).
2. Скачайте полную базу адресов в формате XML.
3. Размер архива составляет примерно **50 ГБ**.
4. Поместите скачанный архив в уже существующую папку `xml_data` в директории проекта.

Структура проекта:

```text
FIAS/1_Подготовка/
├── xml_data/
│   └── gar_xml.zip
├── tools/
│   └── run_all_regions.py
└── requirements.txt
```

> [!IMPORTANT]
> **Распаковывать архив не нужно!**
>
> Скрипт обучения самостоятельно извлечёт из архива все необходимые данные.

### Шаг 2. Установить зависимости

Установите библиотеку NumPy:

```bash
cd FIAS/1_Подготовка/
pip install -r requirements.txt
```

### Шаг 3. Запустить обучение

Откройте терминал в корневой директории проекта и выполните:

```bash
python ./tools/run_all_regions.py
```

**Готово!** Скрипт автоматически обработает необходимые данные из архива ФИАС и выполнит обучение модуля.

Продолжительность обучения зависит от производительности компьютера.
